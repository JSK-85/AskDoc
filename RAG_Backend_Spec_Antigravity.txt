RAG Document Q&A System
Backend Engineering Spec
Hand-off document for Antigravity  •  FastAPI + FAISS + Celery + Google Gemini
This document is the single source of truth for building the backend. Follow the sections in order. Every file path, environment variable, and database schema is specified here. Do not deviate from the folder structure or API contract — the frontend is built against it.
1. System Overview
The system has two independent pipelines sharing a common data layer:
Ingestion pipeline — user uploads a PDF or text document; the backend parses it, splits it into overlapping chunks, embeds each chunk using Google Gemini's embedding API, and stores vectors in a FAISS index on disk plus metadata in PostgreSQL. This runs asynchronously via Celery + Redis so the HTTP response is immediate.
Query pipeline — user submits a natural-language question; the backend embeds the question with the same Gemini embedding model, runs a cosine similarity search against the FAISS index to retrieve the top-k most relevant chunks, assembles a grounded prompt, calls the Gemini 1.5 Flash LLM, and returns a structured JSON response with the answer and page-level citations.
Data flow summary:
INGESTION:  POST /ingest  →  loader → chunker → Gemini embed → Celery task → FAISS + Postgres
QUERY:      POST /query   →  Gemini embed query → FAISS top-k → prompt builder → Gemini LLM → JSON

6. Database Models (db/models.py)
Two tables. Document holds one row per uploaded file with a status lifecycle. Chunk holds one row per text chunk with its FAISS index position so query results can be traced back to the exact source.
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship
from sqlalchemy import String, Integer, DateTime, ForeignKey, Text, Enum
from datetime import datetime
import enum
class Base(DeclarativeBase): pass
class DocStatus(str, enum.Enum):
    PENDING   = 'pending'
    INGESTING = 'ingesting'
    DONE      = 'done'
    FAILED    = 'failed'
class Document(Base):
    __tablename__ = 'documents'
    id:           Mapped[int]       = mapped_column(Integer, primary_key=True)
    filename:     Mapped[str]       = mapped_column(String(255))
    status:       Mapped[DocStatus] = mapped_column(Enum(DocStatus), default=DocStatus.PENDING)
    total_chunks: Mapped[int]       = mapped_column(Integer, default=0)
    created_at:   Mapped[datetime]  = mapped_column(DateTime, default=datetime.utcnow)
    chunks: Mapped[list['Chunk']]   = relationship(back_populates='document', cascade='all, delete')
class Chunk(Base):
    __tablename__ = 'chunks'
    id:          Mapped[int] = mapped_column(Integer, primary_key=True)
    document_id: Mapped[int] = mapped_column(Integer, ForeignKey('documents.id'))
    faiss_idx:   Mapped[int] = mapped_column(Integer)  # position in the FAISS flat index
    chunk_index: Mapped[int] = mapped_column(Integer)  # 0-based order within document
    page_number: Mapped[int] = mapped_column(Integer)
    text:        Mapped[str] = mapped_column(Text)
    document:    Mapped['Document'] = relationship(back_populates='chunks')
7. Ingestion Pipeline — File by File
7.1  ingestion/loader.py
Accepts a file path, returns a list of {text, page} dicts. PyMuPDF is primary. If a page returns empty text (scanned/image page), skip it with a warning log — OCR is a v2 stretch goal.
import fitz  # PyMuPDF
def load_pdf(path: str) -> list[dict]:
    '''Returns [{text: str, page: int}, ...]. Page is 1-indexed.'''
    doc = fitz.open(path)
    pages = []
    for i, page in enumerate(doc):
        text = page.get_text('text').strip()
        if not text:
            print(f'[loader] Page {i+1} returned no text — possibly scanned. Skipping.')
            continue
        pages.append({'text': text, 'page': i + 1})
    return pages
def load_txt(path: str) -> list[dict]:
    '''Plain text files treated as a single page.'''
    with open(path, 'r', encoding='utf-8') as f:
        text = f.read().strip()
    return [{'text': text, 'page': 1}]
7.2  ingestion/chunker.py
LangChain's RecursiveCharacterTextSplitter — the same chunker used in TalentForge. It tries to split on paragraphs first, then sentences, then words, falling back to characters only as a last resort. Overlap keeps context across chunk boundaries.
from langchain.text_splitter import RecursiveCharacterTextSplitter
import os
CHUNK_SIZE    = int(os.getenv('CHUNK_SIZE', 800))
CHUNK_OVERLAP = int(os.getenv('CHUNK_OVERLAP', 150))
splitter = RecursiveCharacterTextSplitter(
    chunk_size=CHUNK_SIZE,
    chunk_overlap=CHUNK_OVERLAP,
    separators=['\n\n', '\n', '. ', ' ', '']
)
def chunk_pages(pages: list[dict]) -> list[dict]:
    '''Input: [{text, page}]  Output: [{text, page, chunk_index}]'''
    result = []
    idx = 0
    for page in pages:
        splits = splitter.split_text(page['text'])
        for s in splits:
            result.append({'text': s, 'page': page['page'], 'chunk_index': idx})
            idx += 1
    return result
⛑ Note: 
CHUNK_SIZE=800 and CHUNK_OVERLAP=150 are the same values that worked well in TalentForge for technical interview PDFs. Tune CHUNK_SIZE down to 500 for dense legal/financial docs.
7.3  ingestion/embedder.py
Wraps the SentenceTransformers all-MiniLM-L6-v2 model — the same embedding model used in TalentForge for the FAISS-backed RAG system. Runs fully locally (no API calls, no cost per embedding). 384-dimensional output vectors. Model is loaded once at module import and reused across all calls.
from sentence_transformers import SentenceTransformer
import os
EMBED_MODEL = os.getenv('EMBEDDING_MODEL', 'all-MiniLM-L6-v2')
# Load once at startup — SentenceTransformer downloads model on first run (~80MB)
_model = SentenceTransformer(EMBED_MODEL)
def embed_documents(texts: list[str]) -> list[list[float]]:
    '''Embed a batch of document chunks. Returns list of 384-dim vectors.'''
    embeddings = _model.encode(texts, convert_to_numpy=True, show_progress_bar=False)
    return embeddings.tolist()
def embed_query(text: str) -> list[float]:
    '''Embed a single user query. Uses same model as ingestion.'''
    return _model.encode([text], convert_to_numpy=True)[0].tolist()
⛑ Note: 
The same model MUST be used at ingestion and query time — the vectors must live in the same space. Never swap the embedding model without re-embedding the entire corpus (delete faiss_index.bin + faiss_meta.json and re-ingest all documents).
7.4  retrieval/faiss_store.py
FAISS flat cosine index. Vectors are stored in the index; all metadata (doc_id, page, text) is stored in a JSON sidecar file. The two are linked by integer position (FAISS index row number = JSON array index).
import faiss, json, os, numpy as np
DIM        = int(os.getenv('EMBEDDING_DIM', 384))
INDEX_PATH = os.getenv('FAISS_INDEX_PATH', 'data/faiss_index.bin')
META_PATH  = os.getenv('FAISS_META_PATH',  'data/faiss_meta.json')
os.makedirs('data', exist_ok=True)
def _load_index() -> tuple[faiss.Index, list[dict]]:
    if os.path.exists(INDEX_PATH):
        index = faiss.read_index(INDEX_PATH)
        with open(META_PATH) as f: meta = json.load(f)
    else:
        # Inner product on L2-normalized vectors = cosine similarity
        index = faiss.IndexFlatIP(DIM)
        meta  = []
    return index, meta
def upsert_chunks(vectors: list[list[float]], metadatas: list[dict]):
    '''Append new vectors + metadata. FAISS flat index is append-only.'''
    index, meta = _load_index()
    arr = np.array(vectors, dtype='float32')
    faiss.normalize_L2(arr)              # Normalize for cosine similarity
    index.add(arr)
    meta.extend(metadatas)
    faiss.write_index(index, INDEX_PATH)
    with open(META_PATH, 'w') as f: json.dump(meta, f)
def search(query_vector: list[float], top_k: int = 6,
           doc_id_filter: int | None = None) -> list[dict]:
    index, meta = _load_index()
    if index.ntotal == 0: return []
    arr = np.array([query_vector], dtype='float32')
    faiss.normalize_L2(arr)
    scores, indices = index.search(arr, top_k * 3)  # fetch more, then filter
    results = []
    for score, idx in zip(scores[0], indices[0]):
        if idx == -1: continue
        m = meta[idx]
        if doc_id_filter and m['doc_id'] != doc_id_filter: continue
        results.append({**m, 'score': float(score)})
        if len(results) == top_k: break
    return results
7.5  ingestion/tasks.py
Celery task that runs the full ingestion pipeline asynchronously. Updates document status in Postgres at each stage so the frontend can poll progress via GET /status/{doc_id}.
from celery import Celery
from ingestion.loader import load_pdf, load_txt
from ingestion.chunker import chunk_pages
from ingestion.embedder import embed_documents
from retrieval.faiss_store import upsert_chunks
from db.database import get_sync_session
from db.models import Document, Chunk, DocStatus
import os
celery_app = Celery('rag', broker=os.getenv('CELERY_BROKER_URL'))
celery_app.conf.result_backend = os.getenv('CELERY_RESULT_BACKEND')
@celery_app.task(bind=True)
def ingest_document(self, doc_id: int, file_path: str, file_type: str):
    with get_sync_session() as session:
        doc = session.get(Document, doc_id)
        doc.status = DocStatus.INGESTING
        session.commit()
        try:
            pages   = load_pdf(file_path) if file_type == 'pdf' else load_txt(file_path)
            chunks  = chunk_pages(pages)
            texts   = [c['text'] for c in chunks]
            vectors = embed_documents(texts)   # Gemini batch embed
            metadatas = []
            db_chunks = []
            for i, (chunk, vec) in enumerate(zip(chunks, vectors)):
                metadatas.append({'doc_id': doc_id, 'text': chunk['text'],
                                  'page': chunk['page'], 'chunk_index': chunk['chunk_index']})
                db_chunks.append(Chunk(document_id=doc_id,
                    faiss_idx=0,  # updated below after we know the base index
                    chunk_index=chunk['chunk_index'], page_number=chunk['page'],
                    text=chunk['text']))
            upsert_chunks(vectors, metadatas)  # writes to FAISS + JSON sidecar
            session.add_all(db_chunks)
            doc.total_chunks = len(db_chunks)
            doc.status = DocStatus.DONE
            session.commit()
        except Exception as e:
            doc.status = DocStatus.FAILED
            session.commit()
            raise self.retry(exc=e, countdown=5, max_retries=2)
8. Generation — File by File
8.1  generation/prompt_builder.py
Assembles the grounded prompt. The system message is intentionally strict — it mirrors the grounding and citation approach used in Nexora and TalentForge: answer only from context, always cite page numbers.
SYSTEM_PROMPT = '''You are a precise document assistant.
Answer ONLY using the context passages provided below.
Do not use any outside knowledge. If the answer is not in the context, respond:
  'I could not find this in the uploaded document.'
Always reference the page number where you found the answer, e.g. (page 4).
Be concise and factual. Do not speculate.'''
def build_prompt(question: str, chunks: list[dict]) -> str:
    context_parts = []
    for i, c in enumerate(chunks, 1):
        context_parts.append(f'[Context {i} | Page {c["page"]}]\n{c["text"]}')
    context_str = '\n\n'.join(context_parts)
    return f'{SYSTEM_PROMPT}\n\nContext:\n{context_str}\n\nQuestion: {question}'
8.2  generation/llm_client.py
Gemini 1.5 Flash client. Temperature 0.2 for factual, deterministic responses. Max output tokens 800 — keeps answers concise and avoids context window blowout.
import google.generativeai as genai
import os
genai.configure(api_key=os.getenv('GEMINI_API_KEY'))
LLM_MODEL = os.getenv('GEMINI_LLM_MODEL', 'gemini-1.5-flash')
def generate_answer(prompt: str) -> str:
    model = genai.GenerativeModel(LLM_MODEL)
    response = model.generate_content(
        prompt,
        generation_config=genai.types.GenerationConfig(
            temperature=0.2,
            max_output_tokens=800,
        )
    )
    return response.text

9.3  api/routes/ingest.py  —  POST /api/v1/ingest
from fastapi import APIRouter, UploadFile, File, Depends, HTTPException
from api.dependencies import verify_api_key
from db.database import get_db
from db.models import Document, DocStatus
from ingestion.tasks import ingest_document
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select
import aiofiles, os, uuid
router = APIRouter()
UPLOAD_DIR = '/tmp/rag_uploads'
os.makedirs(UPLOAD_DIR, exist_ok=True)
ALLOWED_TYPES = {'application/pdf': 'pdf', 'text/plain': 'txt'}
@router.post('/ingest', status_code=202)
async def ingest(file: UploadFile = File(...),
                 db: AsyncSession = Depends(get_db),
                 _=Depends(verify_api_key)):
    if file.content_type not in ALLOWED_TYPES:
        raise HTTPException(400, 'Only PDF and TXT files are supported')
    file_type = ALLOWED_TYPES[file.content_type]
    safe_name = f'{uuid.uuid4()}.{file_type}'
    file_path = os.path.join(UPLOAD_DIR, safe_name)
    async with aiofiles.open(file_path, 'wb') as f:
        await f.write(await file.read())
    doc = Document(filename=file.filename, status=DocStatus.PENDING)
    db.add(doc)
    await db.commit()
    await db.refresh(doc)
    ingest_document.delay(doc.id, file_path, file_type)
    return {'doc_id': doc.id, 'status': 'pending',
            'message': 'Ingestion started. Poll /api/v1/status/{doc_id} for progress.'}
@router.get('/status/{doc_id}')
async def get_status(doc_id: int, db: AsyncSession = Depends(get_db)):
    doc = await db.get(Document, doc_id)
    if not doc: raise HTTPException(404, 'Document not found')
    return {'doc_id': doc.id, 'filename': doc.filename,
            'status': doc.status, 'total_chunks': doc.total_chunks}
@router.get('/documents')
async def list_documents(db: AsyncSession = Depends(get_db)):
    result = await db.execute(select(Document).order_by(Document.created_at.desc()))
    docs = result.scalars().all()
    return [{'doc_id': d.id, 'filename': d.filename,
             'status': d.status, 'total_chunks': d.total_chunks} for d in docs]
9.4  api/routes/query.py  —  POST /api/v1/query
from fastapi import APIRouter, Depends
from pydantic import BaseModel
from api.dependencies import verify_api_key
from ingestion.embedder import embed_query
from retrieval.faiss_store import search
from generation.prompt_builder import build_prompt
from generation.llm_client import generate_answer
import time, os
router = APIRouter()
TOP_K = int(os.getenv('TOP_K', 6))
class QueryRequest(BaseModel):
    question: str
    doc_id: int | None = None
class Source(BaseModel):
    page: int
    excerpt: str
    doc_id: int
class QueryResponse(BaseModel):
    answer: str
    sources: list[Source]
    latency_ms: int
@router.post('/query', response_model=QueryResponse)
async def query(req: QueryRequest, _=Depends(verify_api_key)):
    t0 = time.time()
    q_vec  = embed_query(req.question)                      # RETRIEVAL_QUERY task type
    chunks = search(q_vec, top_k=TOP_K, doc_id_filter=req.doc_id)
    prompt = build_prompt(req.question, chunks)
    answer = generate_answer(prompt)                        # Gemini 1.5 Flash
    sources = [Source(page=c['page'], excerpt=c['text'][:200], doc_id=c['doc_id'])
               for c in chunks]
    return QueryResponse(answer=answer, sources=sources,
                        latency_ms=int((time.time() - t0) * 1000))

13. CORS & Deployment Notes
Development: CORS is allow_origins=['*']. This is correct for local dev.
Production: Replace '*' with the exact Lovable domain, e.g. https://yourapp.lovable.app
The frontend needs to know the backend URL. Set VITE_API_BASE_URL in Lovable's environment settings.
Set VITE_API_KEY in Lovable's environment to match the API_KEY in the backend .env.
The FAISS index (data/faiss_index.bin) must be on a persistent volume in production — it is not recreated on restart. The docker-compose.yml already mounts ./data as a volume for this reason.
